# Locio — installateurs

Ce dépôt sert uniquement à distribuer les installateurs de **Locio**, l'équipe d'agents IA pour les entreprises (https://locio.net).

- **Il ne contient pas le code source de Locio.** Locio est un logiciel propriétaire ; son code n'est pas publié.
- Téléchargez la dernière version dans [Releases](https://github.com/Nadir-DNA/agenthub-releases/releases/latest) : `.exe` pour Windows, `.dmg` pour macOS, `.AppImage` ou `.deb` pour Linux.
- L'application se met à jour d'elle-même à partir de ce dépôt (fichier `latest.json` signé).
